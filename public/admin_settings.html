관리자 설정
강효근 관리 교회 · 교구 · 구역

이 설정은 어디에 적용되나요?

발령 등으로 소속이 바뀌면 여기서 한 번만 수정하면 됩니다. 아래 항목이 이 설정을 따라갑니다:

  • 신규 일정 등록의 구분 + 번호 드롭다운 (예: 581 / 582 / 583 구역·조모임)
  • 교구전체모임 참석 대상자 범위 (관리 교회 + 관리 교구 성도)
  • 출석률 집계 시 교구전체모임 의무 대상 판정

관리 소속 설정

서울중앙교회 소속일 때 교구전체모임 대상이 이 교구로 한정됩니다.

비워두면 관리 교구의 구역 목록(조직 관리 데이터)을 자동으로 사용합니다. 신규 일정의 번호 드롭다운이 이 순서대로 표시되며, 첫 번째 번호가 기본값이 됩니다.

구글 캘린더 연동

아래 URL을 구글 캘린더에 "URL로 추가" 하면, 일반 모임/설교·상담 일정·심방 일정이 모두 구글 캘린더로 한 방향(교회앱 → 구글) 자동 동기화됩니다.
이 URL에는 상담·심방 메모 같은 민감한 개인정보가 포함되어 있으니 본인 외에는 절대 공유하지 마세요.

연동 방법 보기
  1. PC 브라우저로 calendar.google.com 접속 (모바일 앱에서는 URL 캘린더 추가가 안 됩니다)
  2. 왼쪽 하단 "다른 캘린더" 옆 + 버튼 → "URL로 추가" 클릭
  3. 위 연동 URL을 붙여넣고 "캘린더 추가" 클릭
  4. 추가되면 스마트폰 구글 캘린더 앱에도 자동으로 동기화됩니다

※ 구글 정책상 외부 URL 캘린더는 보통 8~24시간 주기로만 새로고침됩니다. 새 일정을 등록했는데 바로 안 보여도 정상이며, 구글 쪽 새로고침 주기라 저희 쪽에서 더 빠르게 만들 수는 없습니다.

URL이 외부로 유출된 것 같으면 재발급하세요. 재발급하면 기존에 연동된 구글 캘린더는 더 이상 갱신되지 않습니다.
